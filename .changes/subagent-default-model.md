- `settings.subagentDefaultModel` now works: a `rlm.spawn` / `rlm.create_session` that does not pin a model resolves this setting first (it previously had no effect at all), falls back to the parent session's live model otherwise, and fails the spawn loudly — naming the refused selector and the `allowedModels` patterns — when the configured model cannot be resolved or is outside the daemon allowlist.
